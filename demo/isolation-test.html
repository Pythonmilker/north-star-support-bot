Shadow DOM isolation test

Tents, packs, and layers for the long trail. (A deliberately broken page used to test the widget.)

This page is intentionally hostile. Its CSS sets box-sizing: content-box, does button { all: unset }, forces input { font-size: 30px }, rotates every svg 180°, and paints links lime. The widget below is unaffected because it lives entirely inside a Shadow DOM. If the isolation ever breaks, you will see it happen here.

Integration is one line — exactly what a client pastes into their own site: 

<script src="north-star-bot.js" data-position="bottom-right"></script>
